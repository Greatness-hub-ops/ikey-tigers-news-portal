# Ikey Tigers News Portal

A student news portal about UCT Rugby Football Club, the Ikey Tigers, produced by Chulumanco Nkalashe for SPLS 305 (Sport Reporting) as part of work-integrated learning in 2026.

This is an independent student project. It is not the official club website. For official information, visit [ikeytigers.com](https://ikeytigers.com/).

The whole portal is one self-contained file, `index.html`, served with GitHub Pages.
